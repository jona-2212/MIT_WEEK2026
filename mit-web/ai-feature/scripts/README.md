# Utilitas pengembangan

Tujuan: menampung script kecil ketika ada kebutuhan engineering yang nyata. Belum ada utilitas tambahan yang diperlukan pada fondasi ini; gunakan perintah uv langsung pada [README](../README.md).

Jika script ditambahkan, dokumentasikan input/output, prasyarat, efek file/jaringan, dan cara menjalankannya. Jangan menyimpan kredensial atau menjadikan script jalur dependency manager kedua. Konvensi mengikuti [development rules](../docs/engineering/DEVELOPMENT_RULES.md).
